====================================
Navegación en GitHub
====================================

GitHub es una plataforma de control de versiones donde los proyectos se organizan en repositorios. A continuación, te mostramos cómo explorar un repositorio de manera eficiente.


**Estructura de un Repositorio**

Un repositorio de GitHub generalmente tiene la siguiente estructura:

- **README.md**: Archivo de bienvenida con una descripción del proyecto.
- **docs/**: Carpeta con la documentación del proyecto (puede incluir archivos `.rst` o `.md`).
- **src/** o **app/**: Código fuente del proyecto.
- **tests/**: Pruebas unitarias o de integración.
- **.github/**: Configuraciones para CI/CD, plantillas de issues y PRs.
- **requirements.txt** o **package.json**: Dependencias del proyecto.
- **.gitignore**: Lista de archivos ignorados en el control de versiones.



**Cómo Explorar Archivos en GitHub**


1. **Usar la Barra de Búsqueda**
   - En la página del repositorio, usa la barra de búsqueda para encontrar archivos o directorios específicos.

2. **Navegar en las Ramas**
   - GitHub permite cambiar entre ramas usando el botón "main" (o "master") en la parte superior.

3. **Ver el Historial de Cambios**
   - Cada archivo tiene un historial de cambios accesible desde la pestaña "History".

4. **Descargar el Código**
   - Puedes descargar el repositorio en formato `.zip` o clonarlo con:
   git clone https://github.com/usuario/repositorio.git
